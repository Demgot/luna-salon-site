# Luna — салон красоты в Смоленске

Адаптивный сайт без сторонних runtime-зависимостей. Требуется Node.js 20+.

```sh
npm run dev
npm run build
npm test
```

Сервер разработки: порт 5173 (или PORT). Готовая статическая сборка: dist/. Данные салона: content.js. Статус материалов и интеграций: MATERIALS.md.

Без подтверждённых материалов сайт публикует только предоставленные название и город, абстрактную графику и ссылку на исходную страницу. Запись не имитируется. Недостающие разделы скрыты.
